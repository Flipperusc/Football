- 项目仓库：`https://github.com/Flipperusc/Football.git`
- 服务器系统：Ubuntu 22.04/24.04
- 域名示例：`football.example.com`
- 项目目录：`/var/www/football`
- Next.js 内部端口：`3000`

**1. 域名解析**

在域名 DNS 控制台添加：

```
类型: A
主机记录: football
记录值: 你的服务器公网 IP
```

如果用根域名：

```
类型: A
主机记录: @
记录值: 你的服务器公网 IP
```

云服务器安全组放行：

```
22    SSH
80    HTTP
443   HTTPS
```

不要对公网开放 `3000` 和 `5432`。

**2. 安装基础环境**

SSH 登录服务器后执行：

```
sudo apt update
sudo apt install -y git nginx postgresql postgresql-contrib curl
```

安装 Node.js 20+，并启用 pnpm：

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

nvm install 20
nvm use 20

corepack enable
corepack prepare pnpm@9.12.3 --activate
```

**3. 创建 PostgreSQL 数据库**

```
sudo -u postgres psql
```

进入 psql 后执行，密码请换成强密码：

```
CREATE USER football_user WITH ENCRYPTED PASSWORD '换成强数据库密码';
CREATE DATABASE football_team OWNER football_user;
GRANT ALL PRIVILEGES ON DATABASE football_team TO football_user;
\q
```

**4. 拉取项目并配置环境变量**

```
sudo mkdir -p /var/www
sudo chown -R $USER:$USER /var/www

cd /var/www
git clone https://github.com/Flipperusc/Football.git football
cd /var/www/football
```

创建 `.env`：

```
cp .env.example .env
nano .env
```

建议写成这样：

```
DATABASE_URL="postgresql://football_user:换成强数据库密码@127.0.0.1:5432/football_team?schema=public"

DEEPSEEK_API_KEY="你的 DeepSeek API Key"
DEEPSEEK_MODEL="deepseek-v4-flash"

ADMIN_USERNAME="admin"
ADMIN_PASSWORD="换成强后台密码"
ADMIN_SESSION_TOKEN="换成随机长字符串"
```

生成随机 `ADMIN_SESSION_TOKEN`：

```
openssl rand -hex 32
```

注意：默认的 `admin123` 不能用于生产环境。

**5. 配置上传图片持久目录**

你的项目会把头像和球队照片写到 `public/uploads/...`，建议放到独立持久目录：

```
sudo mkdir -p /var/lib/football/uploads/players
sudo mkdir -p /var/lib/football/uploads/team-photos
sudo chown -R $USER:$USER /var/lib/football

mkdir -p /var/www/football/public
ln -sfn /var/lib/football/uploads /var/www/football/public/uploads
```

以后备份时要备份 `/var/lib/football/uploads`。

**6. 安装依赖、迁移数据库、构建项目**

```
cd /var/www/football

pnpm install --frozen-lockfile
pnpm prisma generate
pnpm prisma migrate deploy
pnpm build
```

这里生产环境要用：

```
pnpm prisma migrate deploy
```

不要用项目里的 `pnpm prisma:migrate`，因为它对应的是 `prisma migrate dev`，更适合本地开发。

**7. 用 PM2 启动 Next.js**

```
sudo npm install -g pm2

cd /var/www/football
pm2 start "pnpm start -- -p 3000 -H 127.0.0.1" --name football-team
pm2 save
pm2 startup
```

`pm2 startup` 会输出一行 `sudo ...` 命令，把那行复制执行一次即可。

查看运行状态：

```
pm2 status
pm2 logs football-team
```

本机测试：

```
curl -I http://127.0.0.1:3000
```

**8. 配置 Nginx 绑定域名**

创建配置：

```
sudo nano /etc/nginx/sites-available/football
```

写入，把域名改成你的：

```
server {
    listen 80;
    server_name football.example.com;

    client_max_body_size 10M;

    location /uploads/ {
        alias /var/lib/football/uploads/;
        try_files $uri =404;
        access_log off;
        expires 30d;
    }

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

启用站点：

```
sudo ln -s /etc/nginx/sites-available/football /etc/nginx/sites-enabled/football
sudo nginx -t
sudo systemctl reload nginx
```

现在可以访问：

```
http://football.example.com
```

**9. 配置 HTTPS**

```
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d football.example.com
```

验证自动续期：

```
sudo certbot renew --dry-run
```

完成后访问：

```
https://football.example.com
```

**10. 后续更新项目**

以后每次更新代码，按这个顺序：

```
cd /var/www/football

git pull
pnpm install --frozen-lockfile
pnpm prisma generate
pnpm prisma migrate deploy
pnpm build
pm2 restart football-team
```

更新前建议备份：

```
pg_dump -h 127.0.0.1 -U football_user football_team > football_backup.sql
tar -czf football_uploads_backup.tgz /var/lib/football/uploads
```
